# Professional Design MCP Options

## Design-Focused MCP Servers (Actually Available)

### 1. **21st.dev Magic** ⭐ RECOMMENDED
- **What it does**: Creates crafted UI components inspired by top design engineers
- **Setup**: https://github.com/21st-dev/magic-mcp
- **Best for**: Professional UI components for Flutter/React/etc
- **Cost**: Check their site

### 2. **Recraft** 🎨
- **What it does**: Generate raster AND vector (SVG) images
- **Setup**: https://github.com/recraft-ai/mcp-recraft-server
- **Best for**: Custom icons, illustrations, branding
- **Bonus**: Can create your own styles, vectorize images

### 3. **Orshot**
- **What it does**: Generate images from custom design templates
- **Setup**: https://github.com/rishimohan/orshot-mcp-server
- **Best for**: Consistent branded graphics

### 4. **Image Generation (Replicate Flux)**
- **What it does**: AI image generation via Replicate
- **Setup**: https://github.com/GongRzhe/Image-Generation-MCP-Server
- **Best for**: Mockups, concept art, backgrounds

### 5. **Fal.ai MCP**
- **What it does**: FLUX, Stable Diffusion, MusicGen models
- **Setup**: https://github.com/raveenb/fal-mcp-server
- **Best for**: High-quality AI-generated images directly in Claude

## What I Recommend for DatingApp

**Option A: 21st.dev Magic + Widgetbook**
1. Use 21st.dev Magic MCP to generate professional UI component designs
2. Implement them in your Widgetbook catalog
3. Get best of both worlds: AI-assisted design + code-based consistency

**Option B: Recraft for Custom Branding**
1. Generate vector icons, illustrations for your app
2. Create consistent visual style
3. Export SVGs, integrate into Flutter

**Option C: Hybrid Approach** (My favorite)
1. Use **Recraft MCP** for branding (logo, icons, illustrations)
2. Use **21st.dev Magic** for component design inspiration
3. Build everything in **Widgetbook** for long-term maintainability
