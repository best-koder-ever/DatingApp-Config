# GitHub Pages Starter

This folder contains publish-ready content for a portfolio page.

## Recommended Setup

Option A. Organization page
- Create repository named best-koder-ever.github.io
- Put index.md from this folder at repository root
- Enable GitHub Pages in repository settings
- Final URL target: https://best-koder-ever.github.io

Option B. Project page
- Create repository such as portfolio-site
- Put index.md in root
- Enable Pages
- Use generated project URL
